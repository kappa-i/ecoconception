## 🎯 Le projet

> *« Concevoir en groupe un site de promotion touristique en prenant en compte les enjeux environnementaux. »*

**Site cible :** [myswitzerland.com](https://www.myswitzerland.com)

Ce qu'on doit faire :

- 🧭 Concevoir l'UX et optimiser les parcours utilisateurs
- 🎨 Créer le design
- 📋 Appliquer un référentiel d'écoconception ([RGESN](https://ecoresponsable.numerique.gouv.fr/publications/referentiel-general-ecoconception/))
- 💻 Implémenter une partie du site : les pages les plus pertinentes
- ⚙️ Utiliser un framework de développement adapté

---

## 📦 Livrables

- [ ] Maquettes
- [ ] Code source (ce repo)
- [ ] Présentation finale / rapport : analyse du site existant, démarche et justification des choix, résultats
- [ ] Rapport personnel d'une page : analyse critique (approche écoconception, problèmes rencontrés…)
- [ ] PV de séance, à poster dans le canal Teams **après chaque séance**
- [ ] Autoévaluation et évaluation des pairs, à envoyer **individuellement par Teams au dernier cours**

| Critère | Poids |
|---|---|
| **Écoconception** : choix justifiés en design et en développement | **60 %** |

La note de groupe est pondérée selon l'évaluation par les pairs.
